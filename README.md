# Hey, I'm Bruscheto 👋

I build useful tools, music projects, and things to play with. Here are a few selected works:

- **[Albert Course Planner](https://chromewebstore.google.com/detail/lndleikbfacmkakhcfflpgnlapoekmoa)** — Plan NYU classes with a visual calendar, conflict checks, and auto-fetched RMP ratings through APIs.
- **[Voicings](https://github.com/Bruscheto/Voicings-Library)** — Capture and explore jazz piano voicings with notation and playback.
- **[Sammi Klavier](https://sammiklavier.com/)** — A custom portfolio for pianist Sammi Chen, using Astro, and Sanity for CMS.
- **[Wavelength](https://wavelength-game.netlify.app/)** — A bilingual guessing game built with friends, for friends.

Thanks for stopping by. Feel free to explore!
